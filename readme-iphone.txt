FROM AN IPHONE:
1. Download the ZIP into Files.
2. Open Netlify in Safari and select your existing MULA site.
3. Go to Deploys and manually deploy the ZIP if the upload option accepts a ZIP. If it needs a folder, unzip in Files and upload that folder instead.
4. Keep index.html at the site root. Don't create a new Netlify site.
5. Ensure Netlify Forms/form detection is enabled, redeploy if it was just enabled, and submit a test vote. Check the Forms dashboard to verify it is recorded.
6. For email alerts on every new vote, configure a submission email notification for form mula-votes within Netlify.

This ZIP is not deployed automatically, and notification emails need to be configured in Netlify.
